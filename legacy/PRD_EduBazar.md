# PRD - EduBazar.shop

## 1. Product Overview
**Name:** EduBazar.shop  
**Type:** Online Course Selling Platform  
**Tagline:** "Learn. Grow. Succeed."  
**Target Audience:** Students, Professionals, Entrepreneurs

## 2. Features
- Hero Section with animated slider
- Featured Courses Section
- Categories Section
- Testimonials Slider
- Statistics Counter
- Newsletter Signup
- Footer with links

## 3. Design Requirements
- Modern, clean design
- Smooth animations (CSS + JS)
- Responsive (mobile + desktop)
- High-quality images from Unsplash
- Color Scheme: Primary Blue (#4F46E5), Secondary Orange (#F59E0B)

## 4. Pages
- Home Page (single page with all sections)

## 5. Tech Stack
- HTML5
- CSS3 (with animations)
- JavaScript (vanilla)
- Swiper.js for sliders
- AOS (Animate On Scroll)
- Font Awesome icons

## 6. Sections
1. Navigation Bar
2. Hero Slider (3 slides)
3. Stats Counter
4. Popular Courses (6 cards)
5. Categories (4 categories)
6. Testimonials (slider)
7. CTA Section
8. Footer
